# Preview-first generate Apply + history warning_codes sanitization

**Date:** 2026-09-10 21:26
**Files:** frontend/e2e/helpers.js, frontend/src/utils/compositionCandidateLifecycle.js, frontend/src/utils/compositionCandidateLifecycle.test.js, frontend/src/store/musicStore.js, README.md, docs/browser-playback.md, THIRD_PARTY_NOTICES.md
**Severity:** high

## Problem

`$aif-verify` for expressive V2 playback failed `e2e/playback-mixer.spec.js`: generation stayed preview-only, so `waitForCompositionNotes` timed out on empty `editedMusicJson`. After clicking Apply, commit returned 422 because freeform LLM/projection warning strings exceeded history `warning_codes` max length (80). Task 9 also required flagging root LICENSE (CC0) vs README (MIT) without changing the license.

## Root Cause

1. E2E helper still assumed generate wrote the working composition directly; preview-first staging left notes only on `generationCandidate`.
2. Apply mapped `candidate.warnings` (human sentences and `code: message` projection text) straight into durable `ai.warning_codes`, which the history schema rejects when entries are empty or longer than 80 characters.
3. LICENSE inconsistency was noted in the plan but never surfaced in operator-facing docs.

## Solution

- `createProjectAndGenerate` waits for `generation-candidate-panel`, clicks `generation-apply`, then waits for working notes; logs `[FIX:e2e-fake-generate]` success/failure diagnostics.
- Added `toHistoryAiWarningCodes` and used it on generate/edit/motif/develop/arrange/reharmonize durable Apply payloads.
- Flagged CC0 LICENSE vs historical README MIT claim in README, `docs/browser-playback.md`, and `THIRD_PARTY_NOTICES.md` for owner resolution.

## Prevention

- Any e2e path that needs a working composition after LLM generate must Apply (or use a fixture install helper)—never only click Generate.
- History provenance must sanitize display warnings into bounded codes before commit; cover freeform + `code: message` cases in unit tests.
- When a plan says “flag X for owner resolution,” put the flag in shipped docs in the same change that completes the docs task.
