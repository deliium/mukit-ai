# AI region edit panel missing defaultTargetTrackIds import

**Date:** 2026-09-08 14:56
**Files:** frontend/src/components/AiRegionEditPanel.jsx, frontend/src/utils/playbackEvents.js, frontend/src/utils/playbackEvents.test.js, frontend/src/utils/playbackTracks.js
**Severity:** high

## Problem

V2 verify failed ESLint (`max-warnings 0`). `AiRegionEditPanel` called `defaultTargetTrackIds` after its import was replaced by `countV2FeatureSummary`, so defaulting AI edit tracks threw `ReferenceError` at runtime. Related unused bindings also failed lint in playback compile helpers.

## Root Cause

During Composition V2 UI wiring, the panel gained a V2 feature-count import but the prior `defaultTargetTrackIds` import was removed instead of kept alongside it. Playback schedule helpers used rest-destructure omit patterns (`{ originalIndex, ...event }`) and unused `parameter`/`anySolo` locals that ESLint `no-unused-vars` rejects.

## Solution

- Restored `defaultTargetTrackIds` import and kept `countV2FeatureSummary`.
- Logged `[FIX:ai-region-track-defaults]` when track targets are defaulted (counts/mode only).
- Removed unused automation `parameter` args; stripped `originalIndex` via explicit delete helper; dropped dead `anySolo` in gain resolution; cleaned unused test imports.

## Prevention

- When adding an import in a component that already uses another helper, keep both imports or run `npm run lint` before claiming the task done.
- Prefer `delete`/`omit` helpers over unused rest bindings when ESLint has no `_` ignore pattern.
- Treat verify lint failures as release blockers for frontend V2 work.
- Regression: `pianoRollSelection.test.js` asserts `AiRegionEditPanel.jsx` still imports and calls `defaultTargetTrackIds` alongside `countV2FeatureSummary`.
