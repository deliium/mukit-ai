# Playwright V2 acceptance helpers mismatch fake LLM fixtures

**Date:** 2026-09-08 18:24
**Files:** frontend/e2e/helpers.js, frontend/e2e/helpers.test.js, frontend/e2e/v2-user-journey.spec.js, frontend/package.json
**Severity:** high

## Problem

`$aif-verify` Task 11 Playwright journeys failed:

1. `v1-user-journey` / `v2-user-journey` timed out waiting for notes after generate — backend returned `422` (sections sum ≠ duration) or fixture constraint failures (`strings` missing; expressive fixture skipped when sections were user-specified).
2. `v1-upgrade-to-v2` failed note-sequence equality because fixtures use `id: null` and open-path `ensureCompositionNoteIds` assigns hydration UI IDs.
3. Follow-on: toggling `accent` on the expressive first note removed an already-present articulation; checking notation after piano-roll edits saw empty `musicXml` (stale clear + debounce cancel on tab switch).

## Root Cause

E2E helpers only overwrote `#durationBars` and left UI defaults (`sections` summing to 20, `instruments=piano,bass,strings`). Fake LLM requires:

- empty/unspecified sections for the 4-bar expressive fixture (`sections_user_specified=false`)
- instrument lists satisfiable by fixtures (`piano,bass`, not `strings`)

Note-id comparison treated hydration-assigned ids as migration fidelity failures. The V2 journey also asserted notation after edits that intentionally clear `musicXml` until a piano-roll debounce refresh completes.

## Solution

- `prepareFakeLlmPrompt` fills instruments=`piano,bass`, clears sections, sets duration; logged under `[FIX:e2e-fake-generate]`.
- `compareNoteSequences` / `noteIdsCompatible` allow null source ids vs hydration-assigned opened ids.
- `editArticulationViaStore` is idempotent (skip toggle when articulation already present); `[FIX:e2e-articulation]` logs.
- V2 journey checks OSMD notation before piano-roll edits (same order as V1).
- Added `e2e/helpers.test.js` and included it in `npm test`.

## Prevention

- When writing fake-LLM Playwright helpers, sync every prompt field that affects fixture selection and constraint gates (duration, sections, instruments, key), not only duration.
- Migration equality checks must treat hydration-only note ids separately from persisted canonical ids.
- Assert notation while generate-provided `musicXml` is still present, or explicitly await `refreshMusicXmlFromEditedComposition` before leaving the piano-roll tab.
- Run V1/V2 Playwright journeys against a live fake-LLM stack before marking Task 11 complete.
