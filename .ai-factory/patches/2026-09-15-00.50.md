# Fix theme repair routing and sparse accompaniment integrity

**Date:** 2026-09-15 00:50
**Files:** backend/app/services/llm_music_generator.py, backend/app/services/composition_validator.py, backend/tests/test_llm_staged_composer.py, backend/tests/test_composition_validator.py
**Severity:** high

## Problem

After provider/streaming fixes, generation reached validate then 502’d with:

- `theme_target_missing` (Creative theme target region is empty)
- `empty_required_track` for melody (16/20 bars) and violin harmony (20/20 bars)
- `repair_actions.target = compose_melody`
- `validation.thematic` all realized while `theme_target_missing` still listed
- `Repair budget exhausted`

## Root Cause

1. **Stale theme diagnostics:** `validate_composition` merges prior `THEME_DIAGNOSTIC_CODES` from state. Repair kept those errors; a later successful `realize_themes` did not clear them, so `theme_target_missing` resurrected after clean thematic outcomes.
2. **Wrong repair routing:** `_infer_failed_stage` checked `empty_required_track` before theme codes. Messages containing “melody” stole routing to `compose_melody` instead of `plan_themes`.
3. **Harsh accompaniment density:** harmony/pad used the same per-bar floor as melody, so sustained violin at ~1 event/bar failed under `complex` (and fought real pad writing). Melody prompts also encouraged leaving mechanical theme targets sparse, undercutting the density floor.

## Solution

- On successful theme realization, strip theme diagnostic codes from `validation_diagnostics`.
- Prefer `THEME_DIAGNOSTIC_CODES` over `empty_required_track` in `_infer_failed_stage`.
- Soften harmony/pad/rhythm density to ~0.5 events/bar (like bass).
- Melody prompts state the exact integrity minimum and no longer tell the model to leave mechanical targets empty.
- Tests for routing, stale-theme strip, and softer pad/harmony density.

## Prevention

- Stage successes that resolve a diagnostic family must clear that family from state before validate’s prior merge.
- Keep theme routing ahead of role-haystack heuristics that match substrings in error messages.
- Density floors should match musical role (sustain vs melody), and prompts must quote the same numbers validators use.
