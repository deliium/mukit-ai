# Wire Arrange/Harmony candidate actions and clear verify lint gaps

**Date:** 2026-09-10 22:35
**Files:** frontend/src/components/ArrangementPanel.jsx, frontend/src/components/HarmonyTimelinePanel.jsx, frontend/src/components/ProjectComposerBar.jsx, frontend/src/store/musicStore.js, frontend/eslint.config.js, frontend/src/store/musicStore.arrangement.test.js, frontend/src/store/musicStore.test.js, frontend/src/store/musicStore.project.test.js, frontend/src/store/musicStore.versionHistory.test.js
**Severity:** high

## Problem

`/aif-verify` failed Task 12: store APIs for arrangement/reharmonize Reject, Compare, Apply-as-branch, and audition existed, but Arrange and Harmony panels only exposed Discard/Apply. Lint also failed (`URLSearchParams` undeclared; unused imports). Conflict recovery offered Reload only despite copy saying “save as a new branch.”

## Root Cause

Preview-first store work landed ahead of panel wiring. Development was used as the reference UI, but Arrangement/Harmony were left on the older Discard/Apply surface. ESLint globals omitted `URLSearchParams` after `projectApi` started building query strings with it. Conflict UX stopped retries correctly but never exposed the Save-as-branch recovery path that needs a CAS refresh before forking.

## Solution

- Wired ArrangementPanel to `rejectArrangementCandidate`, `refreshArrangementComparison`, and Apply-as-branch (with busy guards and compare summary).
- Wired HarmonyTimelinePanel to audition, Compare, Reject, and Apply-as-branch against existing store actions.
- Added `saveConflictAsNewBranch` (refresh project CAS tokens, then `apply-as-branch` with local draft) and conflict controls in ProjectComposerBar.
- Declared `URLSearchParams` in eslint globals; removed unused `compositionSourceFingerprint` import; fixed unused test arg.
- Added store tests for arrangement reject/compare, reharmonize reject/compare/audition, and conflict save-as-branch.

## Prevention

- When Task deliverables say “add Reject/Compare/Apply-as-branch,” verify each candidate panel (not only the store and Develop panel) before marking complete.
- Keep browser globals used by new API helpers listed in `eslint.config.js` in the same change.
- For 409 recovery UX, implement both Reload and Save-as-branch together when user-facing copy mentions both.
