# Assemble ValidationError mislabeled as LLM provider failure

**Date:** 2026-09-07 11:29
**Files:** backend/app/services/llm_music_generator.py, backend/app/services/composition_planner.py, backend/tests/test_llm_staged_composer.py
**Severity:** high

## Problem

After successful form → harmony → melody → bass → accompaniment stages,
`POST /llm/generate-music-json` failed with `LLM provider request failed: ValidationError`
(HTTP 502). Logs showed assemble starting then immediate failure with no DeepSeek HTTP call.

## Root Cause

`assemble_composition` merged looser `ComposerTrackDraft` / `ComposerDraftNote` models into
strict `Composition` / `NoteEvent`. Draft pitch was only length-checked; canonical notes
require scientific pitch via `_midi_pitch_number`. Invalid pitches, events past
`duration_ticks`, or duplicate track IDs raised pydantic `ValidationError` only at assemble.

`_assemble_composition` did not catch `ValidationError`, so the exception escaped LangGraph
into `generate_music_json`'s broad `except Exception`, which logged `"LLM provider/API failure"`
and wrapped the error as a provider failure. That bypassed the in-graph validate → repair loop
and the clearer `InvalidLLMOutputError` path used by JSON stages.

## Solution

1. Soft-fail assemble schema errors into `schema_invalid` diagnostics with inferred
   `failed_stage`, so validate/repair can run instead of crashing the graph.
2. Preserve assemble diagnostics in `_validate_composition` when `music` is missing.
3. Add scientific-pitch validation to `ComposerDraftNote` so bad pitches fail at the owning
   compose stage via `_run_json_stage` → `InvalidLLMOutputError`.
4. Remap leftover outer `ValidationError` to `InvalidLLMOutputError` (defense-in-depth).
5. Log assemble/schema remaps with `[FIX]` prefix and structured extras (no prompts/secrets).

## Prevention

- Never let pydantic `ValidationError` from composition assembly escape as a provider/API error;
  treat schema failures as invalid LLM output (or soft-fail into diagnostics).
- Keep draft contracts aligned with canonical `NoteEvent` / `Composition` constraints for fields
  that will be copied at assemble (especially pitch).
- Add regression tests that assert schema failures raise `InvalidLLMOutputError` and do not
  log `"LLM provider/API failure"`.
